# 確認一覧カード

確認一覧・要確認事項の xlsx を読み込み、1件ずつカードで答えて xlsx に書き戻すページ。https://sayakaokamura.github.io/review-card/

xlsx はブラウザの中だけで読み書きし、どこにも送らない。

## AI がブラウザで操作するとき

ダイアログ（alert・confirm）は出さない。知らせは画面上部の `#notice`（role="status"）に出る。

| すること | 操作する要素 |
|---|---|
| xlsx を読み込む | `#pick`（file の input。名前「xlsx ファイルを選ぶ」）にファイルを渡す。補足（`<機能名>_補足.json`）があれば一緒に渡す（複数選べる） |
| 前回の続きから始めるか | 読み込んだあと `#notice` に出るボタン。`#restoreYes`（続きから始める）／`#restoreNo`（xlsx に書いてあるとおりで始める）。どちらかを押すまでカードは出ない |
| 1件を開く | 上の色付きの点 `.dot`、または一覧の `.item`（画面が広いときはカードの左に出る。狭いときは `#listbar`（一覧）を押すと開く。role="button"。名前は「No.（決定済み／保留／決め直し中／書きかけ／未回答）」）。`#prev`・`#next`、キーの ← → で前後へ |
| 一覧を絞る | `#filters` のボタン（すべて／未回答／書きかけ／保留／QAに起票。確認一覧は区分ごと、要確認事項は業務の分・開発の分・資料の食い違い・資料の書き漏れ・確認の分け方ごと） |
| 答える | カードの `[data-kind]` のボタン。`advice` おすすめどおり（おすすめのある問いだけ）／`answer` 回答を書く／`ask` QAに起票（前の名前は「お客様に確認」。その値・列も読む）／`hold` 保留／`none` 不要。もう一度押すと外れる。押しているものは aria-pressed="true"。キーの 1〜5 でも押せる（この順。おすすめの無い問いでも番号は変わらない） |
| 回答を書く | `answer` を押すと出る `#ans`（必須） |
| 起票する質問の文を直す | `ask` を押すと出る `#qa`（初めは問いの文：確認一覧は確かめてほしいこと、要確認事項は確認内容） |
| 備考を書く | `#memo`（どのボタンのときも書ける。必須ではない） |
| 決める | `#decide`（決定して次へ。キーの Enter でも押せる）。ボタンを押していて、`answer` なら `#ans` が埋まっているときだけ押せる。決めたあとは `#redo`（決め直す）。決め直しでボタンを全部外すと `#decide` は「答えを消す」になり、押すと未回答に戻る。決め直し中のまま保存すると、前に決めた答えのまま書く |
| xlsx に保存する | `#save`（答えを入れた xlsx を保存）。元のファイル名でダウンロードされる |
| 起票分を出す | `#qaout`（起票分を出力）。「QAに起票」にして決定したものを、QA表の列の並び（No・現行機能・対象・質問・確認の内容・BlueMemeの案・参考資料）で `<機能名>_QA起票.xlsx` にダウンロードする。形は QA表に合わせる（シート「QA一覧」、B 列から、1〜3 行に表題、5 行に見出し、6 行から行。回答・回答者・回答日・ステータスは黄色の空欄） |

ページを離れても「このサイトを離れますか」は出ない。保存していない答えはこのブラウザの控え（localStorage）に残り、同じ xlsx を読み込み直すと `#notice` で戻すかを訊く。xlsx に残すには `#save` で保存する。

## 補足（試作）

`<機能名>_補足.json` を xlsx と一緒に読ませると、カードに所見の1行と、資料の原文・現行や開発環境を並べて出す。形は `{"items": {"<No.>": {"所見": "…", "原文": [{"出典": "…", "文": "…"}], "画像": [{"説明": "…", "src": "data:image/png;base64,…"}]}}}`。客先の資料の写しなので、このリポジトリには置かない。

## 書き込む列

列の名前・並びと確認結果の値は、xlsx を作る側に合わせている。作る側で変えたら、このページも合わせて直す。

確認一覧（シート「確認一覧」）も要確認事項（シート「要確認事項」）も、1行ごとに同じ列に書く。無い列は右の端に足す（列の幅・絞り込みの範囲も広げる）。

| | 確認結果 | ほかの列 |
|---|---|---|
| おすすめどおり | 妥当 | |
| 回答を書く | 回答 | 回答 |
| QAに起票 | QAに起票 | QA起票文 |
| 保留 | 保留 | |
| 不要 | 不要 | |
| 備考 | | 備考 |

前の作りの値（違う・お客様に確認・持ち帰り）も読む。前の作りで要確認事項に足した列（要約・要約への回答・検討事項・認識合わせ・QAに起票・不要）は読まず、書き換えもしない。
